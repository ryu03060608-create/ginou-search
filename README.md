# 技能実習・特定技能 職種／分野 検索＋AI診断

技能実習の「移行対象職種・作業」と、特定技能の「特定産業分野・業務区分」を、
キーワード検索・分野フィルタで探せる React アプリです。
さらに **企業HPからAIで候補を提示する「AI診断」モード** を搭載しています。

- **AI診断（URL）**：企業URL（またはHP本文）から、技能実習・特定技能の該当候補を「証拠の強さ（強／中／弱）」＋根拠付きで提示
- **受入れ診断**：作業内容から受入れ可否・人数枠を試算
- **職種一覧**：キーワード検索・分野フィルタ
- ライト／ダークテーマ対応

## AI診断モードについて

- **できること**：HP本文をLLM（Claude）で解析し、公式の職種・作業リストの中から該当しそうな候補を提示します。
- **できないこと（重要）**：HPから分かるのは「業種の当たり」までです。在留資格の可否は、実際に外国人が従事する具体的作業・必須業務の比率・受入れ体制で決まり、HPには通常載っていません。
  そのため結果は **確率ではなく「証拠の強さ」** です。最終的な可否は必ず監理団体・登録支援機関・出入国在留管理局でご確認ください。**技人国（技術・人文知識・国際業務）は対象外**です。
- **APIキー**：バックエンドを持たない静的サイトのため、利用者自身の Anthropic APIキーを入力して使います（ブラウザの localStorage にのみ保存、Anthropic以外へは送信しません）。共用端末では使用後に消してください。
- **HP取得**：ブラウザのCORS制約のため、リーダー（r.jina.ai）経由で本文を取得します（対象URLが同サービスに送信されます）。取得できない場合は本文の貼り付けに対応。

> 幻覚（実在しない職種の生成）を防ぐため、LLM には `src/data.js` の公式リストを「選択肢」として渡し、その中からのみ候補を選ばせています。

## 技術構成

- [Vite](https://vitejs.dev/)（開発サーバー・ビルド）
- [React 18](https://react.dev/)

## 使い方

初回のみ、依存パッケージをインストールします。

```bash
npm install
```

開発サーバーを起動（ブラウザで表示を確認しながら開発）:

```bash
npm run dev
```

本番用にビルド:

```bash
npm run build
```

ビルド結果をローカルで確認:

```bash
npm run preview
```

## データについて

- 技能実習：JITCO「移行対象職種・作業一覧」（令和8年4月10日時点）
- 特定技能：出入国在留管理庁「特定技能」制度（分野別運用要領）

> 制度・分野・職種は改正が頻繁です。正確・最新の情報は必ず公式サイトでご確認ください。
> データは `src/data.js` にまとまっているので、そこを編集すれば更新できます。
