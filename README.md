# 技能実習・特定技能 職種／分野 検索＋AI診断

技能実習の「移行対象職種・作業」と、特定技能の「特定産業分野・業務区分」を、
キーワード検索・分野フィルタで探せる React アプリです。
さらに **企業HPからAIで候補を提示する「AI診断」モード** を搭載しています。

- **AI診断（URL）**：企業URLか会社名を入れるだけ。AIがウェブ検索・ページ取得で調べ、技能実習・特定技能の該当候補を「証拠の強さ（強／中／弱）」＋根拠付きで提示
- **受入れ診断**：作業内容から受入れ可否・人数枠を試算
- **職種一覧**：キーワード検索・分野フィルタ
- ライト／ダークテーマ対応

## AI診断モードについて（バックエンド構成）

利用者は **URLか会社名を入れるだけ**。APIキーの入力は不要です。AIの呼び出し・ウェブ検索・キーの保持はすべて**バックエンド（`server/index.mjs`）側**で行います。

- **できること**：Claude が `web_search` / `web_fetch` で企業サイトや公開情報を調べ、公式の職種・作業リストの中から該当しそうな候補を提示します。
- **できないこと（重要）**：調べて分かるのは「業種の当たり」までです。在留資格の可否は、実際に外国人が従事する具体的作業・必須業務の比率・受入れ体制で決まり、公開情報には通常載っていません。
  そのため結果は **確率ではなく「証拠の強さ」** です。最終的な可否は必ず監理団体・登録支援機関・出入国在留管理局でご確認ください。**技人国（技術・人文知識・国際業務）は対象外**です。
- **APIキー**：サーバーの環境変数 `ANTHROPIC_API_KEY` に置きます（ブラウザには一切出ません）。
- **幻覚対策**：`src/data.js` の公式リストを「選択肢」として渡し、その中からのみ候補を選ばせています。

### バックエンドの起動（自前サーバー）

```bash
npm install
npm run build          # フロント(dist)を作る
ANTHROPIC_API_KEY=sk-ant-xxxx npm start
# → http://localhost:8787 で公開。スマホからも同URL（HTTPS化推奨）でアクセス可
```

環境変数：
- `ANTHROPIC_API_KEY`（必須）… Anthropic のAPIキー
- `PORT`（任意、既定 8787）
- `AI_MODEL`（任意、既定 `claude-opus-5`。コストを抑えるなら `claude-sonnet-5`）

フロントを別ホストで配信する場合は、ビルド時に API の場所を指定できます：

```bash
VITE_API_BASE=https://api.example.com npm run build
```

## 技術構成

- [Vite](https://vitejs.dev/) + [React 18](https://react.dev/)（フロント）
- [Express](https://expressjs.com/) + [Anthropic SDK](https://github.com/anthropics/anthropic-sdk-typescript)（バックエンド）

## 開発

初回のみ、依存パッケージをインストールします。

```bash
npm install
```

フロントの開発サーバー（表示確認用。AI診断はバックエンド起動が別途必要）:

```bash
npm run dev
```

本番用にビルド:

```bash
npm run build
```

ビルド結果をローカルで確認:

```bash
npm run preview
```

## データについて

- 技能実習：JITCO「移行対象職種・作業一覧」（令和8年4月10日時点）
- 特定技能：出入国在留管理庁「特定技能」制度（分野別運用要領）

> 制度・分野・職種は改正が頻繁です。正確・最新の情報は必ず公式サイトでご確認ください。
> データは `src/data.js` にまとまっているので、そこを編集すれば更新できます。
