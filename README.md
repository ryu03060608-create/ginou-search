# 技能実習・特定技能 職種／分野 検索

技能実習の「移行対象職種・作業」と、特定技能の「特定産業分野・業務区分」を、
キーワード検索・分野フィルタで探せる React アプリです。

- 上部のタブで **技能実習 / 特定技能** を切り替え
- キーワード検索（職種名・作業名・分野名にマッチ）
- 分野チップで絞り込み
- ライト／ダークテーマ対応

## 技術構成

- [Vite](https://vitejs.dev/)（開発サーバー・ビルド）
- [React 18](https://react.dev/)

## 使い方

初回のみ、依存パッケージをインストールします。

```bash
npm install
```

開発サーバーを起動（ブラウザで表示を確認しながら開発）:

```bash
npm run dev
```

本番用にビルド:

```bash
npm run build
```

ビルド結果をローカルで確認:

```bash
npm run preview
```

## データについて

- 技能実習：JITCO「移行対象職種・作業一覧」（令和8年4月10日時点）
- 特定技能：出入国在留管理庁「特定技能」制度（分野別運用要領）

> 制度・分野・職種は改正が頻繁です。正確・最新の情報は必ず公式サイトでご確認ください。
> データは `src/data.js` にまとまっているので、そこを編集すれば更新できます。
